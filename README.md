# Shortlist link

This GitHub Pages site forwards visitors to the [Shortlist app](https://miguel-shortlist.profound-9684.chatgpt.site/).

The `data/jobs.enc.json` file is updated nightly from the private job search repository. It contains only encrypted job data and previous picks; the decryption key is stored as a secret in the private workflow and the Shortlist app. Picks made in the app are stored in its database and sync between devices signed in to the same ChatGPT account.
